# Memo

Application de flashcards 100 % manuelle, sans compte, pub ou abonnement.

## Fonctions
Matières, chapitres, cartes recto/verso, modification/suppression, recherche, révision, répétition espacée simple, mode sombre, export/import JSON.

## Lancer sur PC
Dans ce dossier : `python -m http.server 8000`, puis ouvrir `http://localhost:8000`.

## iPhone/iPad
Pour l'installer comme une app, publier le dossier sur un hébergement HTTPS (par exemple GitHub Pages), puis Safari > Partager > Sur l'écran d'accueil.

## Sauvegarde
Les données sont locales au navigateur. Utiliser régulièrement Exporter.
